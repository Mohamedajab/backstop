02 / UNDER THE HOOD

One refresh.
A little less panic.

Ten people asking for the same expired content shouldn’t mean ten trips to a struggling origin.

01

Check the last good copy

Fresh content returns immediately. Recently stale content is still useful, so it returns while a refresh happens.

02

Let one request do the work

A Durable Object coordinates each resource. Concurrent cold requests wait for the same origin fetch.

03

Know when to stop

A 2-second timeout and failure cooldown protect the origin. After 65 seconds, old content stops being a fallback.
